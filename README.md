# 贝叶斯近似测量不变性分析代码与说明

本仓库提供论文《连续收缩与稀疏选择的贝叶斯近似测量不变性比较》的程序代码说明，涵盖模拟数据生成、JAGS模型设定、模型拟合、收敛诊断、非不变检测、参数返真性评价、结果汇总、作图及实证分析。

研究比较小方差正态先验（SVN）、弱稀疏spike-and-slab先验（SSP-W）与强稀疏spike-and-slab先验（SSP-S）。程序集中组织在同一份文档中，按章节查阅，无需按研究拆分文件夹。

## 软件与依赖

论文分析使用R 4.4.2。运行前需安装JAGS，并在R中安装以下扩展包：

```r
install.packages(c(
  "rjags", "coda", "readxl", "dplyr", "tidyr", "purrr",
  "stringr", "tibble", "ggplot2", "openxlsx", "readr"
))
```

`parallel`随R提供，无需单独安装。`rjags`调用独立安装的JAGS；仅安装R包不能替代安装JAGS。RStudio为可选编辑环境。

## 使用顺序

1. 下载代码说明文件，阅读第1、2节，准备R、JAGS及所需R包。
2. 在本地建立独立工作目录，按文档生成数据、模型文件和分析结果；核对各代码块使用的输入、输出路径。
3. 先选择一个模拟条件和少量重复数据，检查数据生成、模型拟合及结果提取能否衔接，再开展完整模拟。
4. 运行模拟分析时，先准备第3、4节的数据与模型，再运行第5、6节；扩展条件参见第7节，汇总与作图参见第8节。
5. 运行实证分析时，另行准备所需ESS数据，先定义第4节的模型及后续使用的函数，再按第9节执行数据处理与模型估计。

完整模拟包含多个条件、每个条件500次重复及多链MCMC估计，运行时间取决于硬件、并行设置和模型收敛情况。正式复现时应使用论文规定的重复次数、采样设置与收敛处理规则。

## 输入数据与路径

- 模拟数据由文档中的代码生成。
- 实证分析读取`ESS7e02_3.csv`，该原始数据不包含在这三个说明文件中。请通过欧洲社会调查官方渠道获取相应数据，核对数据版本、变量名称和编码，并遵守其使用要求。

## 复现与解释

SVN根据差异参数的95%后验可信区间是否包含零判定非不变；SSP根据后验包含概率（PIP）判定，SSP-W和SSP-S的阈值分别为0.75和0.70。

评价指标包括收敛表现、真阳率、假阳率、RMSE、标准误比及95%后验可信区间覆盖率。指标定义、可评价参数范围及未收敛重复的处理应与论文保持一致。

随机数设置、软件版本、数据处理与抽样步骤、MCMC设置和收敛筛选均可能影响数值结果。代码说明用于展示分析流程，不表示所有章节已经作为一个完整程序在独立环境中重新验证。正式引用或复现时，请保留所使用的文件版本，并记录运行环境与任何调整。
