本研究比较小方差正态先验（SVN）与两种稀疏设定的离散层级spike-and-slab先验（SSP）在贝叶斯近似测量不变性分析中的表现。模拟分别考察样本量、非不变程度与比例，以及组数、题目数和载荷—截距非不变共现方式的影响，并进行跨国实证分析。结果表明，三种方法的点估计误差接近。SVN收敛稳定、假阳率低，但对小幅非不变较保守；弱稀疏SSP检测率最高，但部分条件下假阳率较高；强稀疏SSP的综合表现较均衡。组数或题目数增加未改变基本比较关系；非不变共现时，SSP较稳定，SVN的载荷识别和因子方差恢复更易受影响。实证分析中，强稀疏SSP识别出更多非不变参数，但潜均值及国家排序与SVN高度一致。不同先验对非不变检测、不确定性估计和计算表现具有不同影响，方法选择应结合非不变结构与研究目的。
